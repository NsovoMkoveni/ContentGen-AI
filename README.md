# ✨ ContentGen AI

A responsive web-based content generator built with **Python, Flask, HTML, CSS and JavaScript**.

ContentGen AI allows users to enter a topic, select a content type, tone, target audience and content length, then generate formatted content within seconds.

---

## 🚀 Features

- ✨ Content generation
- 🔄 Regenerate content
- 📝 Multiple content types
- 🎨 Multiple writing tones
- 🎯 Target audience selection
- 📏 Short, medium and long content
- 📋 Copy generated content
- ⬇️ Download content as a text file
- 💾 Save generated content
- 📚 Content history
- ↩️ Load saved content
- 🗑️ Delete saved content
- 🧹 Clear all history
- 🌙 Dark mode
- ☀️ Light mode
- 📱 Responsive design
- 🔐 Basic browser-side content escaping

---

## 📝 Available Content Types

ContentGen AI currently supports:

- LinkedIn Post
- Professional Email
- Advertisement
- YouTube Description
